# Mobile App for Online Assessment — K–12 EdTech

**Role:** Product Manager  
**Date in source portfolio:** 2024  
**Audience:** K–12 schools  
**Focus:** EdTech and mobile assessment  
**Status in source portfolio:** Shipped

## Overview

The Mobile App for Online Assessment was developed to extend online assessment management from the web platform to mobile devices.

The experience was intended to help schools upload, organize and track online assessments while bringing core desktop capabilities to a mobile-first environment.

## Problem

The source portfolio identifies a need to make assessment administration accessible on mobile and achieve web-to-mobile parity. Educators and administrators needed to carry out important assessment activities without being limited to the desktop experience.

## My role and contribution

As Product Manager, the source portfolio describes my work as collaborating with engineering, design and school operations teams; leading discovery and delivery of mobile assessment features; defining requirements for uploading assessment materials; supporting organization of tests by class or subject; defining capabilities for tracking student progress; and helping prioritize a mobile experience that retained core web functionality.

## Product capabilities

- Uploading online assessment materials.
- Organizing assessments by class or subject.
- Tracking student progress.
- Accessing core assessment workflows on mobile.
- A more consistent experience across web and mobile.

## Intended value

The product aimed to reduce friction in assessment administration, improve access for school users and provide visibility into student performance from mobile devices.

**Measurement note:** The source portfolio does not include adoption, task-completion, time-saving or learning-outcome metrics. No quantified impact is claimed here.
